# Theory notes

Each theory has its own folder as `<slug>/THEORY.md`. The table below is the index. There are 154 theory notes.

Later additions stay in that theory's folder, not in a shared dump:

- `reviews/` — related reviews (not the original paper)
- `research/` — modern tests and follow-ups
- `scripts/` — verification

One hundred fifty-four theory notes. Kaplan, Hudson and Langley 1989 was dropped as a duplicate of the Kaplan coalescent hitchhiking note. Notes live one-per-folder under `theories/`. Each theory has its own note.
